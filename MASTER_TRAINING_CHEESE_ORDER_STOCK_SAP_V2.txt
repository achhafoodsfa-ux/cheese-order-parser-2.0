SLICE RULES
Slices exist in 1kg and 800gm.
If 800gm is explicitly written, use 800gm SKU. Otherwise use 1kg.
Yellow 1kg = FG-02-0028; Yellow 800gm = FG-02-0038.
White 1kg = FG-02-0023; White 800gm = FG-02-0037.
1 CTN of either slice = 18 PCS.
Burger Slice / Orange Slice = Yellow Slice.
CRITICAL: “2 kg burger slice” means 2 PCS of 1kg Yellow Slice, NOT 2 CTN.
“2 ctn burger slice” means 2 × 18 = 36 PCS.

CONVERSION
2kg Block: 1 CTN = 10 PCS = 20 KG.
2kg Shred/Dice: 1 CTN = 5 PCS = 10 KG.
1kg Slice: 1 CTN = 18 PCS.
800gm Slice: 1 CTN = 18 PCS.
Nivora 2.5kg: 1 CTN = 4 PCS = 10 KG.
Formula: PCS = CTN × PCS_PER_CTN.
If quantity is already PCS/PKT/PACKET, DO NOT multiply.

AMBIGUOUS QUANTITY
If “20 Achha” has no unit, use context only if clearly established. Otherwise flag NEEDS REVIEW. Do not make unsafe assumptions.

DUPLICATES
Same customer + same FG = merge quantities.
Different customers = NEVER merge.

SAP OUTPUT

FG CODE + 2 TABS + QTY + 5 TABS + HO-WH + 2 TABS + CHEESE

FG-01-0042		25					HO-WH		CHEESE
Use actual TAB characters. Never replace tabs with spaces.
Customer name and Customer SAP Code MUST be outside the SAP code block.
The SAP code block must contain ONLY SAP lines. No product names, totals, CTNs, KG, comments or explanations.

STOCK SHEET / ORDERSHEET
Typical structure:

Row 7 = SAP Codes
Row 8 = Product Names
Row 9 onward = Customer/order rows
Column A = Sr #
Column C = Customer Name
Column F = Remarks/Phone
Column G onward = product quantities
For Stock Sheet entry:
1. Identify customer and customer row.
2. Identify product using Row 7 SAP code or Row 8 product name.
3. Enter CTN quantity into the correct product column.
4. Do NOT enter PCS into a CTN field.
5. Recalculate totals.
6. Verify totals.
7. Never write into a random/unknown product column.
When cleaning the sheet, do not damage master rows or merged cells.
